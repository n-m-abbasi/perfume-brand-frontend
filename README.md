# **README — LAURA Luxury Perfume Landing Page**

A modern, fully responsive **RTL (Persian)** landing page designed for a fictional luxury perfume brand called **LAURA**.  
This project showcases front‑end design skills, including layout composition, typography, responsive behavior, and UI/UX aesthetics.

---

## ✨ **Features**

- RTL layout optimized for Persian content  
- Elegant hero section with layered gradients  
- Product collection grid with hover animations  
- Brand story section with split layout  
- Highlighted features grid  
- Modern navbar with blur effect  
- Responsive design for mobile and tablet  
- Clean and organized CSS architecture  

---

## 🧱 **Tech Stack**

- **HTML5**  
- **CSS3**  
- **Google Fonts (Vazirmatn)**  
- Pure front‑end (no frameworks)

## 📸 **Sections Overview**

- **Navbar** — fixed, transparent, blurred background  
- **Hero Section** — large background image, gradient overlay, call‑to‑action buttons

- **Brand Story** — image + text split layout  
- **Features** — icon‑based grid  
- **Footer** — multi‑column layout with subscription form

## 📱 **Responsive Design**

The layout adapts smoothly to:

- Mobile screens  
- Tablets  
- Smaller laptops  

Using CSS grid, flexbox, and media queries.

---

## 🔧 **How to Use**

1. Clone or download the repository  
2. Place all images inside the `image/` folder  
3. Ensure `style.css` is inside `static/`  
4. Open `index.html` in any browser

No build tools or dependencies required.
